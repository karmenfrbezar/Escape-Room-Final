# STEM Escape room - Laboratorij ludog znanstvenika
## Python program

Python CLI aplikacija razvijena je za potrebe escape room izazova kako bi na interaktivan način prenijela završnu poruku i lozinku igračima, primjenom standardnih modula `time` i `random` za teletype ispis teksta. 

Igrači moraju unijeti rješenje zagonetki kako bi program krenuo sa ispisom rješenja. 
Nakon unosa točne šifre program na samom kraju ispisuje tajnu lozinku potrebnu igračima za otključavanje izlaza.
